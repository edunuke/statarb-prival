Investment Thesis Pure Risk Compression & Convex Tail Hedging

Predicting absolute asset returns is noisy and fragile. This engine abandons return forecasting entirely. Instead, it continuously identifies mispriced structural pairs, dynamically tunes entry gates using AI, and optimizes purely for minimum variance and friction reduction.

1 · Mathematical Mispricing

  • Measured, Not Assumed: Mispricing is quantified via the Kalman Innovation z-score \((e_t)\). We measure exact standard deviations from a live, dynamically hedged fair-value ratio.
  • Durable Foundations: The universe is re-screened every 20 days using C-accelerated motif distance and Engle-Granger tests to ensure only structurally cointegrated pairs are traded.

2 · Adaptive AI Entry Gates

  • Contextual Bandits: A LinUCB machine learning agent dynamically adjusts entry sensitivity \(\in \{1.50, 1.85, 2.25\}\,\sigma\).
  • Regime Awareness: The agent restricts capital deployment during calm or fragile regimes, and aggressively expands the entry gate during high-VIX market dislocations to harvest widening spreads.

3 · No-Noise Optimizer

  • The Breakthrough: We stripped expected return (\(\mu\)) from the SLSQP objective function. Capital is allocated purely inverse to spread volatility.
  • The Result: This prevents "toxic concentration" in high-yield, high-risk spreads. The engine maintains strict sector neutrality and scales effective gross exposure efficiently without unnecessary turnover drag.

The Engine, in One Sentence

A modular 3-stage architecture handles data processing, risk filtering, and order generation cleanly and transparently.

  • Screen (every 20d) — finds durable cointegrated pairs.
  • Track (every 5d) — re-measures spread divergence & pauses on regime shift.
  • Execute (real time) — times entries, balances sleeves, and prints low-impact orders.

Each stage is a separate engine, so a failure or retune in one never leaks into the others.

  • Single Ticker NAV: Capped at 15% net exposure.

Liquidity & Execution

  • ADV Cap: Orders capped at 1.5% 20-day ADV.

Next Steps Phase 2: Live Micro-Allocation Checklist

The algorithmic logic is frozen and stable. Transitioning from out-of-sample simulation to live exchange routing requires deploying the following production infrastructure layers.

1. State-to-Broker Reconciliation

  • The Risk: Disconnect between local algorithm memory and actual broker holdings (e.g., rejected orders, corporate actions).
  • The Action: Implement a hard API reconciliation loop. If local \(\Delta\) vs Broker \(\Delta\) exceeds a $10 tolerance, trigger a fatal exception and halt trading to prevent catastrophic overallocation.

2. API Order Routing & Kill Switches

  • The Risk: Execution delays or exchange auction halts.
  • The Action: Wrap the Market-On-Open (MOO) blotter in a FIX/REST API payload (e.g., IBKR ib_insync) scheduled via cron job at 09:00 AM EST. Implement Time-in-Force (TIF) cancel mandates for unresolved auction fills.

3. Implementation Shortfall Telemetry

  • The Risk: Live bid/ask slippage exceeds the 1.5 bps backtest threshold, bleeding alpha.
  • The Action: Log the target \(\text{Price}_{\text{T-1}}\) against the actual filled \(\text{Price}_{\text{T}}\). Institute a circuit breaker that pauses the strategy if the rolling 5-day slippage breaches 5 bps.

4. Sector Dollar-Neutrality Constraint

  • The Risk: Sudden, macro-driven sector rotations damaging a beta-neutral but dollar-imbalanced book.
  • The Action: Inject a rigid SLSQP constraint (\(\sum W_{\text{long}} + \sum W_{\text{short}} = 0\) per sector) before applying 3x+ portfolio leverage, sacrificing marginal yield for total sector immunity.

FAQ · One Should We Switch to Passive Limit Orders?

Performance

Backtest better, live worse

  • Mathematically improves the backtest by erasing the $1,906.98 fee drag today.
  • But it will likely degrade live performance through adverse selection.
Risk Profile

Higher execution risk

  • Stat-arb captures rapid mean-reversion — if you post a passive limit, you only fill when the spread moves against you.
  • On the best trades (snap-back in minutes), your resting order is left unfilled — you miss exactly the alpha the model was built to capture.
Verdict

Keep MOO aggressive execution

  • Paying 1.5–3.0 bps to guarantee you capture the divergence (and the structural-break exit) is a necessary cost of doing business in fast mean-reversion.
Bottom Line

Execution aggressiveness is not the fee line to optimize. The 1.5 bps MOO fill is what guarantees the edge is actually captured in live markets.

FAQ · Two Should We Force Strict Sector Dollar-Neutrality?

Performance

Decreases absolute returns

  • Adding the hard equality constraint \(\sum W_{\text{long, sector}} + \sum W_{\text{short, sector}} = 0\) shrinks the feasible set of the SLSQP optimizer.
  • The engine is forced to reject profitable cointegrated pairs simply because no offsetting pair exists to balance sector dollars.
Risk Profile

Significantly improves risk

  • Mathematically eliminates the threat of a macro-driven sector rotation (e.g., a regional banking crisis) blowing up a beta-neutral but dollar-imbalanced book.
Verdict

Only at 3x+ leverage

  • Implement only if you intend to run high portfolio leverage (3x+), where surviving sector tail-risk matters more than raw unlevered yield.
  • Below that, the return sacrifice is not worth the protection.
Bottom Line

Sector dollar-neutrality is a leverage-enabler, not a return-enhancer. Unlevered, it only costs yield.

FAQ · Three Should We Add Trailing Z-Score Stops?

Performance

Higher turnover, shorter holds

  • Decreases average holding time, which increases turnover and execution fees.
  • You avoid full \(-2.75\sigma\) stop-outs, but get prematurely chopped out of trades that hit normal noise before fully reverting.
Risk Profile

Improves downside volatility

  • Cutting the position the moment reversion momentum stalls limits exposure to structural breaks the BOCPD engine hasn't flagged yet.
Verdict

Worth testing — carefully

  • Requires careful tuning so the trailing buffer isn't so tight it generates excessive churn and fee drag.
  • Gate twice: once for residual reversion, once for realized slippage.
Bottom Line

If the goal is a higher Sortino and you accept a sub-7% unlevered return, implement Sector Dollar-Neutrality. If you want the 7.64% return the deck reports, leave the architecture exactly as it is.
