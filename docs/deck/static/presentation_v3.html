Investment Thesis Relaxed Neutrality with Convex Risk Compression

Predicting directional market returns is inherently fragile. This strategy eliminates return forecasting (\(\mu\)) entirely, generating uncorrelated alpha by capturing mean-reverting price dislocations between cointegrated equity pairs. The v3.2 engine demonstrates the optimizer was previously starved of allocation room by the 1% beta constraint — relaxing to 5% unlocks conviction-driven sizing while remaining institutional-grade.

1 · Measured Relative Value

  • Kalman Filter Tracking: Trade entries trigger when pair spreads diverge from dynamic equilibrium, measured via innovation residuals \((e_t)\) with delta=1e-4 and observation noise=1e-3.
  • Cointegration Guard: Universe re-screened every 20 days using Engle-Granger ADF (p < 0.04) to guarantee capital is allocated only to statistically linked pairs.

2 · Relaxed Beta Neutrality

  • 5% Beta Cap: The core lever — net beta exposure relaxed from 1% to 5%, enabling the SLSQP optimizer to size positions proportional to conviction.
  • 8% Dollar Exposure: Net dollar neutrality relaxed from 2% to 8%, giving the allocator room to overweight high-conviction sleeves while staying market-neutral.

3 · Minimum-Variance Portfolio Construction

  • No Return-Forecast Noise: Stripping \(\mu\) from the optimizer forces capital allocation purely inverse to spread covariance and variance.
  • Institutional Sizing: With relaxed constraints, the optimizer expresses conviction on top pairs (e.g., XYZ/TROW at +9.65%) while maintaining sector caps, single-stock limits, and gross exposure at 2.80×.

Risk Management Risk Management Features — Embedded Controls

The v3.2 engine embeds 16 layered risk controls that operate continuously across the portfolio lifecycle. These controls are non-negotiable and cannot be overridden by the optimizer.

Position Lifecycle Controls

  • 1. Stop-Loss: Hard Z-score stop at |Z| ≥ 2.20 — immediate exit regardless of P&L.
  • 2. Minimum Holding Period: 2 days — prevents overtrading on noise signals.
  • 3. Maximum Holding Period: 15 days — caps stale position risk.
  • 4. Alpha Staleness Gate: Auto-close if Days_Held ≥ 8 AND Alpha < 0.35.
  • 5. Quarantine: 30-day lockout after stop-loss hit.

Entry Filter Controls

  • 6. Hurst Exponent Filter: Reject pairs with Hurst ≥ 0.43 (non-mean-reverting).
  • 7. Slope T-Stat Filter: Reject pairs with |slope t-stat| ≥ 1.96 (trending spreads).
  • 8. Half-Life Bounds: 1.5–25 days (too fast = noise, too slow = regime break risk).
  • 9. Cointegration P-Value: Re-screened every 20 days, p < 0.04 required.
  • 10. ECDF Noise Filter: ECDF percentile ≥ 0.80, Z-score ≥ 0.50.

Portfolio-Level Controls

  • 11. SPY Beta Overlay: Automatic SPY hedge up to 55% NAV to offset residual market beta.
  • 12. Sector Exposure Cap: 12% net per sector.
  • 13. Single Stock Cap: 45% gross per stock.
  • 14. Net Dollar Exposure: ≤ 8% at all times.
  • 15. Net Beta Exposure: ≤ 5% at all times.
  • 16. Gross Exposure Cap: 2.80× hard limit.
  • 17. ADV Participation: 1.5% of 20-day average daily volume.

Next Steps Phase 3: Live Deployment Checklist

The v3.2 algorithmic logic is frozen and validated across 500 out-of-sample trading days. Transitioning from backtest simulation to live exchange routing requires deploying the following production infrastructure layers.

1. State-to-Broker Reconciliation

  • The Risk: Disconnect between local algorithm memory and actual broker holdings (rejected orders, corporate actions, partial fills).
  • The Action: Implement a hard API reconciliation loop. If local \(\Delta\) vs Broker \(\Delta\) exceeds a $10 tolerance, trigger a fatal exception and halt trading to prevent catastrophic overallocation.

2. API Order Routing & Kill Switches

  • The Risk: Execution delays or exchange auction halts during MOO windows.
  • The Action: Wrap the Market-On-Open (MOO) blotter in a FIX/REST API payload (e.g., IBKR ib_insync) scheduled via cron job at 09:00 AM EST. Implement Time-in-Force (TIF) cancel mandates for unresolved auction fills.

3. Implementation Shortfall Telemetry

  • The Risk: Live bid/ask slippage exceeds the 1.5 bps backtest threshold, bleeding alpha. The v3.2 engine pays $3,203.28 in total fees across 202 trades.
  • The Action: Log the target \(\text{Price}_{\text{T-1}}\) against the actual filled \(\text{Price}_{\text{T}}\). Institute a circuit breaker that pauses the strategy if the rolling 5-day slippage breaches 5 bps.

4. Relaxed Beta Constraint Monitoring

  • The Risk: The 5% beta cap (up from 1%) provides more allocation room but requires tighter monitoring of net beta drift.
  • The Action: Log daily portfolio beta via regression. If net beta exceeds 4% (80% of threshold), trigger a pre-emptive SPY overlay rebalance before the 55% cap is hit. Alert if any single sector exceeds 10% of the 12% cap.
